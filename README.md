# Chat Dashboard

Интерактивный статичный дашборд по одному личному Telegram-экспорту (59 HTML-файлов, ~33 000 сообщений за 2021–2026).

**Страница:** https://<owner>.github.io/chat-dashboard/ после включения Pages.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | каркас SPA (Chart.js 4 через CDN) |
| `app.js` | вся логика: 12 вкладок (Обзор, реестры «Люблю», «Спокойной ночки», Тёмный регистр, Статус, Прикосновения, Подарки, Музыка, Глоссарий имён, Звонки, Паузы, О проекте) |
| `data.js` | агрегированные данные (`window.DATA`), собраны локальным скриптом из сообщений |
| `style.css` | тёмная тема, карточки, тепловые карты |

## Методология

1. Telegram Desktop → «Экспорт истории чата» (только сообщения, 59 HTML-файлов).
2. Локальный парсер разворачивает HTML → `messages.json` (source of truth, не публикуется).
3. Локальный агрегатор считает помесячные серии, события по подстрокам (все цитаты дословные, даты и авторы проверены по первоисточнику).
4. Результат — `data.js`; сайт полностью статичный, без бэкенда и без отправки данных куда-либо.

## Приватность и тон

- Это личная страница-аналитика. Данные — из приватного экспорта, публикация — осознанное решение владельца.
- Тёмные темы (раздел «Тёмный регистр») поданы бережно: статистика по месяцам + журнал эпизодов по датам, без подробностей; часть цитат в журнале урезана по длине.
- Исходный `messages.json`, полный текстовый отчёт и скрипты анализа в этот репозиторий **не входят**.
- Все ключевые события реестров верифицированы по точному тексту сообщений (дата + автор).
